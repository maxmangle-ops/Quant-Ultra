# Quant Ultra

Quant Ultra is an algorithmic trading assistant for the Indian stock market.

## Features

- Live Upstox WebSocket
- Historical Data
- EMA
- RSI
- ATR
- Session VWAP
- Strategy Analyzer
- Risk Manager
- Paper Trading
- Trade Journal
- Performance Dashboard

## Trading Modes

- Paper Trading
- Live Trading (Manual Approval)

## Roadmap

- Telegram Integration
- Paper Trade Monitoring
- Daily Reports
- Broker Execution
